# 差旅报账助手 0.1.26（预发布）

面向 Windows 10 / Windows 11 64 位，本版将补充发票的识别、支付匹配和邮件待办处理连在一起，包含尚未单独发布的 0.1.25 官方网页下载入口改进。

## 更新内容

- 51 发票邮件新增“打开官方下载页”，通过默认浏览器前往官方页面下载 PDF。需要用户验证、确认或点击下载的步骤保留在浏览器中完成。
- 邮件待办详情增加 PDF 拖入区及“选择 PDF 文件”。核对邮件中可用的发票号码、金额后导入当前差旅，成功保存后只关闭对应待办；号码或金额不符、文件不可读或保存失败时保留待办，可重试。原下载文件保留。
- “添加发票与支付”先选择发票／行程单 PDF，再自动识别并按现有分类、金额容差和日期／时间规则与已有支付记录匹配。能够确定的关联直接完成；多个同等候选、支付争用、缺行程或未识别材料仍可在待处理事项中核对。先加发票、后加支付截图也可继续匹配。
- PDF 优先读取原有文字；单页扫描发票新增 Windows 本地 OCR 后备，仅采纳明确的价税合计／小写金额。冲突金额不猜填，未识别的号码和日期留空；多页扫描件保留人工处理。
- 修正重复发票核对：使用原票面金额判断同号重复，保留用户手工修正的费用金额、确认状态和支付关联。
- 增加拖入、选择文件、连续操作锁定、识别失败、保存失败重试、重复导入及自动关联测试。发布脚本支持指定独立 Python 构建环境。

## 使用和升级

关闭旧程序，将新版 ZIP **完整解压到新的程序文件夹**，运行“差旅报账助手.exe”。不要只复制 EXE，也不要在 ZIP 中直接运行。继续使用原数据目录，不要同时运行多个版本操作同一份差旅数据。

遇到网页下载类邮件，打开“导入待处理事项”，选择对应邮件，打开官方下载页；下载完成后，将本地 PDF 拖入该邮件详情中的提示区域即可。

## 验证与已知问题

156 项 Python、235 项 Flutter 测试及静态检查通过。完整私有材料／规则回归 **62/64**，没有新增失败；原有 8.76 元截图金额未识别及其关联场景两项问题仍存在，可人工补录核对。人工预期未改写；私有原件、标注、派生材料和报告不随源码或发行包发布。

本地真实 PDF 已验证文字及扫描副本的金额读取，以及隔离差旅内导入、保存、重新读取和对应邮件待办关闭。扫描副本的部分号码、日期仍可能无法识别，不能保证所有扫描发票都可自动关联。

免安装包从独立源码目录构建，检查包内 Python、PDF 导出／预览、OCR、排版、新增发票模块和实际 EXE／SQLite 启动，附 GPL 全文、第三方声明、对应源码地址与 SHA256 校验文件。OCR 依赖 Windows 本地 OCR 和中文识别语言；其他电脑兼容性仍需试用验证。
