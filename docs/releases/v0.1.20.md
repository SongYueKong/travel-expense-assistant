# 差旅报账助手 0.1.20（预发布）

面向 Windows 10 / Windows 11 64 位。本版汇集 0.1.14 之后的报账核对、PDF 排版和邮件导入改进。

## 更新内容

- **汇总首页**：城市间交通费显示单据数量及申报金额，市内交通费显示申报金额，住宿费显示人数、天数及申报金额。住宿默认 1 人，天数使用含首尾日的出差天数；总金额突出显示加粗人民币大写及阿拉伯数字。
- **多票共用支付**：城际交通可手工选择多张费用发票组成共同支付组，例如多张高铁退票费发票对应一笔实际扣款。按发票合计与一笔实付取较小值，支付只计一次；导出保留各张原件和子编号，共用截图只排一次。支持拆分并释放支付。
- **导出前核验**：缺少城市间交通费、市内交通费或住宿费时列出缺项，可返回检查或核验后继续导出；三类齐全时不额外确认。
- **关联序号**：发票、配套行程单、情况说明、出租车纸票框及支付截图的序号调大、加粗，长截图编号按格子宽度适配。
- **ZIP 邮件附件**：自动读取普通 ZIP 中的多份 PDF，按内容去重，并在 PDF 清单保留邮件、压缩包和包内文件来源。加密、损坏、嵌套压缩及不支持的格式保留具体提示。
- **OFD/XML 提示**：同一封邮件已有 PDF 时，不再因其他附件或压缩包没有 PDF 而产生多余待办；已有记录根据本地邮件来源自动消除这一旧提示，无需再次获取。其他邮件及 PDF 读取错误仍需处理。
- **滴滴发票**：支持英文 `didi` 标识及原文件名辅助分类，修复平台信息技术服务费的类别缺失；核对信息中明确显示费用项目。

## 使用和升级

关闭旧程序，将 ZIP **完整解压到新的程序文件夹**，运行“差旅报账助手.exe”。不要只复制 EXE，也不要从压缩包中直接运行；同一 Windows 用户继续使用原数据目录。不要同时运行多个版本操作同一份差旅数据。

- 已导入材料需要应用新的识别规则时，进入“设置／更多 → 时间匹配／重算”；原有人工关联和已复核材料按保留规则处理。
- 旧版未读取的 ZIP 附件，需要“从邮箱补充发票”重新获取原日期范围。同一邮件已导入 PDF 的 OFD/XML 无 PDF 提示，在新版本打开记录后自动过滤。
- 多票共用支付仅支持城际交通，需先选发票、再选择对应扣款；若原先已关联不同支付，应先解除多余关联。
- ZIP 内只导入 PDF，限压缩包及单个 PDF 各 25 MB、包内 200 项、解压后合计 50 MB。仅有 OFD/XML、加密或损坏的压缩包仍需人工处理。
- 信息技术服务费的识别修复不代表支付已经匹配完成，仍需核对对应支付和出行材料。

## 验证与已知问题

215 项 Flutter 测试、123 项 Python 测试通过。私有真实材料回归 **36/38**，无新增失败；原有 8.76 元截图金额未识别及关联失败两项问题仍存在，可人工补录和核对。真实材料和人工标注未随源码或发行包发布。

本机开发版已完成实际 EXE 隔离启动、SQLite 保存重开检查，并检查过 PDF 汇总、原件编号及共用支付截图排版。免安装包使用独立源码目录构建，并通过包内独立 Python、PDF 导出与预览、本地 OCR、ZIP 邮件与替代格式提示、滴滴服务费识别、Flutter/SQLite 实际启动自检；附 GPL 全文、第三方声明、对应源码地址和 SHA256 校验文件；不包含个人差旅记录、私有样本、邮箱账号或授权码。

截图识别仍依赖 Windows 本地 OCR 及中文识别语言；各邮箱实际连接和其他电脑的兼容性需试用验证。邮箱授权码保存在当前 Windows 用户的凭据管理器中。
