# 差旅报账助手 0.1.11（预发布）

首次公开预发布，面向 Windows 10 / Windows 11 64 位，欢迎跨电脑试用。

## 下载和运行

下载附件中的 `TravelExpenseAssistant-0.1.11-windows-x64-*.zip`，完整解压后双击“差旅报账助手.exe”。不要从压缩包内运行，也不要只复制 EXE。无需另外安装 Python 或 Flutter。

## 已包含的功能

- 邮箱或本地导入发票、行程单和支付截图，分类核对、查看原材料和处理待办。
- 金额容差、日期/时间匹配、优惠辅助判断、多候选人工关联和重复截图检测。
- 酒店收款单位校验、PDF/图片情况说明、出租车纸票登记和粘贴框。
- 伙食补助、差旅独立文件夹管理、分类汇总首页和完整材料 PDF 导出。
- 支付截图支持 A4 横向/纵向、行列各 1～8，本机保存配置；尾页不放大。
- 邮箱账号和授权凭据本机保存，支持九个常用国内个人邮箱域名。

## 验证与已知问题

186 项 Flutter 测试、90 项 Python 测试已通过。已验证随包 Python、SQLite、PDF 导出和预览、OCR、自定义排版及实际 EXE 启动；ZIP 将附 SHA256 校验文件。

私有真实材料回归为 36/38：存在一张 8.76 元截图金额漏识别，连带对应行程未匹配。可人工核对、录入和关联。私有材料和真实邮箱凭据不随包提供。

其他电脑实际兼容性及各邮箱真实账号连接仍需测试；Windows OCR 需要相应中文识别语言。反馈问题时请先遮盖发票、支付截图和邮箱中的个人信息，不要提交密码或授权码。
