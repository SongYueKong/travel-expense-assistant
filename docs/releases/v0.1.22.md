# 差旅报账助手 0.1.22（预发布）

面向 Windows 10 / Windows 11 64 位，本版更新出租车纸票与支付截图的导出排版。

## 更新内容

- 出租车纸票粘贴页改为 **每页 1 行 × 3 列**，每框标注序号和录入的票面金额，例如 `001  ¥35.00`。显示票面金额，费用申报仍沿用原核算规则。
- 出租车票框和支付截图网格的**左边距统一为 2 厘米**。
- 按当前支付截图排版设置计算票框宽高，使用同一套网格尺寸；尾页不足三个票框或不足一页截图时，格子尺寸保持一致。
- 开启“统一所有页面为 A4”时，纸票页直接采用目标方向，避免再次缩放造成与截图格子尺寸不一致。
- 兼容旧版导出清单，从同编号汇总行补取票面金额。缺少有效金额时提示核验，格子过大无法并排放置三个票框时提示增加截图排版行数或列数，避免越界和重叠。

## 使用和升级

关闭旧程序，将新版 ZIP **完整解压到新的程序文件夹**，运行“差旅报账助手.exe”。不要只复制 EXE，也不要在 ZIP 中直接运行。继续使用原数据目录，不要同时运行多个版本操作同一份差旅数据。

重新导出 PDF 即可应用新排版，已有材料无需为本次排版更新重新识别或重新获取邮件。票框尺寸跟随“设置／更多 → 支付截图排版”中的行列与方向设置；若格子过大，按提示增加行数或列数后重试。

## 验证与已知问题

215 项 Flutter 测试、127 项 Python 测试通过。真实材料使用独立私有测试工作区验证，结果 **36/38**，无新增失败；原有 8.76 元截图金额未识别及关联失败两项问题仍存在，可人工补录核对。人工预期未修改，私有样本和测试报告不随发行包或源码发布。

本机开发版已完成实际 EXE 启动及 SQLite 隔离保存重开自检；横向及统一竖向 A4 的票框、金额、20 毫米左边距和尾页样张已逐页检查。免安装包使用独立源码目录构建，并通过包内独立 Python、出租车金额及三列格子、20 毫米左边距、PDF/OCR、Flutter/SQLite 实际启动自检；附 GPL 全文、第三方声明、本版对应源码地址与 SHA256 校验文件。

截图识别依赖 Windows 本地 OCR 和中文识别语言；其他电脑的实际兼容性仍需试用验证。发行包不包含个人差旅记录、票据、邮箱账号或授权码。
