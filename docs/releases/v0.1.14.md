# 差旅报账助手 0.1.14（预发布）

面向 Windows 10 / Windows 11 64 位，本版修复邮件与差旅票据识别问题。

## 更新内容

- 支持电子发票中“经纪代理服务／代订机票”的城际交通分类，保留原有金额识别和核算规则。
- 修复滴滴行程单时间的小时、分钟跨行排版导致行程遗漏的问题。
- 收紧邮件下载待办判断，避免 Steam 等购买收据页脚中的普通“发票”字样触发误提示；邮件解析缓存升级，重新获取后按新规则刷新。
- 自动下载已适配的17win发票短链接。仅接受HTTPS及已核实的下载跳转域名，限25MB；校验后按普通PDF导入。失败保留提示，重新获取邮件会重试。其他平台、登录或验证码页面仍需人工处理。

## 使用和升级

退出旧版本，完整解压新版ZIP到新程序文件夹后运行“差旅报账助手.exe”。不要只复制EXE，也不要从压缩包中直接运行。同一Windows用户继续使用原数据目录。

已有差旅请先在“设置／更多 → 时间匹配／重算”重新识别材料；再使用“从邮箱补充发票”重新获取相关时间范围的邮件，刷新旧提示并自动获取支持的链接发票。不会在程序启动时自动改写既有匹配结果。

## 验证与已知问题

99项Python和194项Flutter测试通过。私有真实材料回归36/38，与上版基线相同，无新增失败；原有8.76元截图金额识别及关联两项问题仍在，可人工处理。真实机票分类、跨行行程和用户提供的17win酒店PDF已使用隔离副本复核。

免安装包包含GPL全文、第三方声明和本版对应源码地址，附SHA256校验文件。不包含个人差旅记录、私有样本或邮箱凭据。其他电脑兼容性和各邮箱真实连接仍需试用验证。
