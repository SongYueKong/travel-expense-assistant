# 差旅报账助手 0.1.13（预发布）

Windows 10 / Windows 11 64 位免安装版，基于 0.1.11 增加以下功能：

- PDF 汇总首页增加最终核算总额的人民币大写，包含已计入的伙食补助。
- 移除汇总页的“核算口径”整段说明。
- 导出后的“查看 PDF”调用 Windows 默认 PDF 软件；历史导出只有一份时直接打开，多份时先选择文件。支持中文、空格和特殊字符路径，文件缺失或默认应用启动失败时提示。
- 排版设置增加“统一所有页面为 A4”，方向沿用所选横向/纵向，内容等比例居中、不裁剪；默认关闭并在本机保存。

## 下载和升级

下载附件中的 Windows x64 ZIP，完整解压后运行“差旅报账助手.exe”，不要从压缩包内运行或只复制 EXE。升级时退出旧版本，将新版解压到新的程序文件夹；同一 Windows 用户继续使用原数据目录。PDF 查看使用系统为 `.pdf` 设置的默认应用。

## 验证与已知问题

194 项 Flutter 测试、94 项 Python 测试及静态检查通过；免安装包另外执行随包 Python、PDF/OCR、实际 EXE 和 SQLite 隔离启动验证。SHA256 校验文件随附件提供。

私有真实材料基线为 36/38，通过情况未退化：仍有一张 8.76 元截图漏识别金额，影响对应行程匹配，可人工处理。其他电脑兼容性和各邮箱真实账号连接仍需试用验证。私有测试材料、差旅记录和邮箱凭据不随源码或发行包公开。
