# 差旅报账助手 0.1.24（预发布）

面向 Windows 10 / Windows 11 64 位，本版改进支付截图金额识别与人工核对体验，包含 0.1.23 的识别修复。

## 更新内容

- 金额识别从固定屏幕区域改为字段用途与相对布局判断。优先读取实付、净支付等字段，位置及字号提供辅助证据；截图上下移动或变长不再依赖原有坐标模板。
- 区分实付、订单、优惠、退款、账户余额、交易金额与记账金额，并交叉核验。多个候选冲突时保留待核对，不强选最大金额。
- 支持微信支付与扫码付款账单、中文日期、转账时间，以及人民币银行转账记录；银行记录须核验支出方向与交易/记账金额一致，避免误读余额。
- 原支付页同时显示一致的退款状态和退款记录时，按扣除退款后的净支付读取；保留原支付与退款依据，避免重复扣减。
- 对有明确用途依据的模糊金额进行区域补识别，并要求多次结果相互印证；补齐折行的转账单号和长收款单位名称。
- 新增“查看金额依据／候选”：查看金额用途及原图框选位置，对照原图填入实际支付净额，保存关联后生效。余额、订单、优惠及退款不提供直接填入实付按钮；部分退款提供核验后的净支付。
- 补充位置移动、长截图、缩放、金额冲突、广告干扰及失败状态测试。保留原有费用分类、时间匹配阈值和报账汇总口径。

## 使用和升级

关闭旧程序，将新版 ZIP **完整解压到新的程序文件夹**，运行“差旅报账助手.exe”。不要只复制 EXE，也不要在 ZIP 中直接运行。继续使用原数据目录，不要同时运行多个版本操作同一份差旅数据。

对已有待处理截图，在“导入待处理事项”点击“重新识别／匹配”，即可更新识别结果及金额依据。选择关联时可以展开“查看金额依据／候选”；未识别截图可通过“显示全部截图”查看并人工指定。人工修正先保留在编辑草稿，保存后生效。

新的字段含义、模糊文字或冲突结算关系仍可能需要人工核对。

本机开发版已通过实际 EXE 启动及 SQLite 隔离保存重开自检。免安装包使用独立源码目录构建，执行包内 Python、语义金额判断、PDF/OCR、排版和 Flutter/SQLite 启动检查，附 GPL 全文、第三方声明、对应源码地址与 SHA256 校验文件。

截图 OCR 依赖 Windows 本地 OCR 和中文识别语言；其他电脑的实际兼容性仍需试用验证。发行包不包含个人差旅记录、票据、邮箱账号或授权码。
